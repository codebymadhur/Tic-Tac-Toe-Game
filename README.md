# 🎮 Tic Tac Toe Game

A simple yet fun implementation of the classic Tic-Tac-Toe game using HTML, CSS, and JavaScript.

## 🧩 Features

- Two-player gameplay on the same device
- Highlighting the winning combination
- Restart functionality
- Clean and responsive UI


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)


## 🧠 How to Play

- Player 1 is **X**, Player 2 is **O**
- Take turns clicking empty squares to mark
- First to line up 3 symbols (horizontally, vertically, or diagonally) wins
- Click "Restart" to play again
