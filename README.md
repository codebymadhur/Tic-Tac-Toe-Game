# 🎮 Tic Tac Toe Game

A fun and simple **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.  
Play with a friend, track wins, and enjoy a smooth UI with animations and hover effects.

---

## 🚀 Live Demo
Play here: [Tic Tac Toe Game](https://codebymadhur.github.io/Tic-Tac-Toe-Game/)

---

## ✨ Features
- 🎯 **Two-player mode** (O and X)
- 🏆 **Win detection** with highlighted winner
- 🤝 **Draw detection**
- 🔄 **Reset & New Game** buttons
- 🎨 Stylish UI with **hover effects**
- 📱 **Responsive design** (works on mobile & desktop)

## 🛠 How to Play
1. Open the game in your browser.
2. Player **O** starts first.
3. Click on an empty box to place your mark.
4. First to align 3 marks **vertically, horizontally, or diagonally** wins.
5. If all boxes are filled without a winner → **Draw!**
